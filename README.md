# 📝 To-Do List Application

A simple Python-based To-Do List application for managing daily tasks efficiently.

## 📌 Internship Task

**Task 2 – Easy: To-Do List Application**

Create a Python application to manage daily tasks efficiently.

## ✨ Features

- Add new tasks
- Display all tasks
- Mark tasks as completed
- Delete unwanted tasks
- Save tasks to a JSON file
- Automatically load saved tasks
- Input validation
- Simple command-line interface

## 🛠️ Technologies Used

- Python 3
- JSON
- File Handling
